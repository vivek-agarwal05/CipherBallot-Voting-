Architectural Workflows Compared

Model 1: Anonymous One-Time Token (Blind Signature / Token Scheme)

Voter identity is verified during phase 1 (token issuance). The ballot is submitted in phase 2 using only the redeemed token.

Model 2: CipherBallot Variant B Architecture (Separated Database Records)

A single atomic transaction inserts an anonymous AES-GCM ciphertext while recording participation in an isolated table.
